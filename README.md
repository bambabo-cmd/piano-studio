# 우리집 연주실 2 · Piano Studio Next

**2.0.0-alpha.4 — 새 반응형 화면을 기본 화면으로 통합**

녹음·악보·재생·메트로놈을 기본 화면에 모으고, 편집은 전체 화면으로 엽니다.
기존 앱의 녹음/AI/음원/편집/편곡/파일 처리 코드에 연결하는 UI 통합판입니다.
예제 음표나 가짜 녹음으로 작동하는 디자인 시안이 아닙니다.

## 기본 화면

- 휴대폰 세로/가로, 태블릿 세로/가로, 넓은 PC 화면에 맞춰 재배치합니다.
- 녹음 · 악보 생성 · 재생 · 메트로놈은 하단에 유지합니다.
- ‘전체 화면 편집’에서 원래 피아노 롤과 도구를 사용합니다.
- 태블릿 가로/PC는 트랙, 악보/음표, 선택 음 속성을 함께 표시합니다.
- 시스템 기본/다크/일반 모드를 제공하고, 첫 실행 기본값은 다크입니다.
- 버전 1 이동 버튼과 기존 버전 2의 곡 저장소를 유지합니다.

## 기존 기능 위치

| 메뉴 | 기능 |
|---|---|
| 곡·파일 | 곡 선택/이름/추가/삭제, 곡 파일 가져오기, JSON/MIDI/악보 내보내기 |
| 녹음·AI | 마이크/MIDI, 겹쳐 녹음, 원음 보관·MP3, 선택 트랙 다시 분석 |
| 트랙·악기 | 빈 트랙, 타이핑, 악기/음량, 음소거/솔로, 녹음 원음 듣기 |
| 박자·편곡 | 박자/탭 정렬, 구간 조절, 음 보정/양손 나누기, 코드/반주/전주/후주 |
| 화면·연습 | 테마, 빠르기/음량, 녹음·재생 메트로놈/카운트인, 독립 메트로놈 설정 |

한글 계이름은 `도도솔솔`처럼 붙이거나 `도 도 솔 솔`처럼 띄어서 입력할 수 있습니다.
`도미솔`은 순차 입력이며 동시에 치는 화음으로 해석하지 않습니다.

## 편집과 저장

편집은 현재 곡의 실제 음표에 즉시 반영됩니다. 시안의 ‘취소 시 전부 폐기’가 아닙니다.
닫기는 수정한 내용을 유지하고, 완료는 저장 트랜잭션 성공을 확인한 뒤 닫습니다.
수정을 취소하려면 기존 ‘되돌리기’를 사용합니다. 저장 실패 시 편집창을 유지합니다.
기존 브라우저 곡 저장 DB `piano-studio-next-v2`와 설정 접두사 `psn-v2-`는 바뀌지 않습니다.
중요한 곡은 ‘곡 파일 저장 (원음 포함)’으로 별도 백업해 주세요.

‘악보 생성’은 현재 음표로 악보를 새로 그립니다. 녹음은 기존 엔진대로 종료 후 자동 분석합니다.
이미 고친 곡을 원음부터 다시 채보하려면 메뉴 → 녹음·AI → 다시 악보 만들기를 사용합니다.
실제 악보는 기존 VexFlow 렌더러와 음표의 손 지정 또는 선택한 분리 기준을 사용합니다.
악보 표시의 확대/축소는 음표 데이터를 바꾸지 않습니다.

## 배포

기존 `.github/workflows/pages.yml`과 Settings → Pages → GitHub Actions 설정을 유지합니다.
저장소 `main`에 이번 업데이트를 커밋하면 기존 워크플로가 새로 빌드/배포합니다.
실제 배포 산출물은 `dist/index.html`이며, 저장소 루트의 안내용 `index.html`은 교체하지 않습니다.
`app/next-boot.js`가 원본 UI 노드를 새 화면으로 옮기고 기존 처리기를 재사용합니다.

화면 연결에 필요한 원본 요소가 없으면, 옮겼던 요소를 복구하고 기존 화면을 보여줍니다.
같은 버전 2의 이전 배치는 주소 끝에 `?ui=classic`을 붙여 열 수 있습니다.
기존 `/preview/`는 예전 독립 시안이며, 기본 실행 화면은 아닙니다.

## 범위와 검증 한계

이번 작업은 UI/기능 연결입니다. AI 정확도, 초기 모델 로딩, 녹음 음량, 자동 손 분리,
편곡 품질의 알고리즘을 개선한 버전은 아닙니다. 기타 악기 선택을 기타 운지/TAB 생성으로
부르지 않습니다. 관련 엔진은 기존 구현 그대로입니다.

로컬에서는 합성 호스트 DOM에 실제 타이핑/되돌리기 발췌 코드를 연결하여 화면/이벤트 흐름을
검사했습니다. 저장은 메모리 트랜잭션 모사이며, 음성/AI/악보 그리기는 모사 처리입니다.
따라서 실제 전체 원본 앱 실행, 실제 IndexedDB, 브라우저 PWA, 휴대폰 마이크,
iPhone/iPad Safari의 검증을 대신하지 않습니다. GitHub 배포는 사용자의 업로드 이후 실행됩니다.
